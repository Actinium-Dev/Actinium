# 内置资源包功能

Actinium 内置 Continuity 和 MCPatcher 资源包功能。资源格式以 Continuity-For-Actinium `4281538`、Angelica `996fb54c` 和 OptiFine 1.12.2 HD U G5 为基线。旧 MCPatcher 扩展 `renderPass`、自定义实体模型和自定义 GUI 不在此范围。

升级时先卸载独立 `continuity`。Actinium 从 `config/continuity.json` 导入开关，不改写原配置文件或已选资源包列表。资源包选择菜单中可单独启用默认连接纹理和玻璃板修复。CTM Mod 存在时由它处理 `.png.mcmeta` 等 CTM 元数据；CleanSkyboxes 存在时由它处理天空层。OptiFine 本体不属于此验证组合。

`Actinium-Connected-Textures.zip` 使用 Angelica 的默认连接贴图，覆盖普通玻璃、16 色染色玻璃及其玻璃板、书架和普通砂岩。从旧版默认包升级时，先删除 `resourcepacks/Actinium-Connected-Textures.zip`，再启动新版 Actinium 安装同名资源包。已选资源包顺序继续生效。

已启用的包提供规则时，Actinium 自动应用对应功能。视频设置的「资源包」页可按功能关闭，保存设置后重载资源。

旧玻璃板规则为匹配的原版玻璃板生成 MCPatcher 网格。透明玻璃板使用薄面，染色玻璃板保留 1/8 厚度和端面，兼容内置的玻璃板修复包。资源包提供自定义玻璃板模型时保留其几何。

随机实体以客户端首次收到实体时的位置和群系执行出生条件。村民子职业可从集成服务端读取；远程服务器未下发子职业时，只按客户端可用的职业信息匹配。`mcpatcher/line/fishingline.png` 和 `mcpatcher/line/lead.png` 由随机实体开关控制。

`mipmap.properties` 可按路径配置独立纹理。方块与物品共用原版图集，`textures/atlas/blocks.png` 或旧 `terrain.png` 的规则应用于整个图集。

## 实测清单

在 Cleanroom OpenGL 和 Outlands SDL-GPU 上分别运行无光影模式与该后端支持的光影包。使用同一存档与资源包，同一场景分别启用和关闭快速方块渲染。选择用户已经安装的光影包，并记录具体版本。用同一版本的无规则资源包作为画面对照。

- **重载**：分别启用目录包、ZIP、服务端资源包，验证同名规则的优先级。切换资源包两次并重进世界，检查旧纹理、旧色图和物品网格均已失效。
- **地形**：并排放置玻璃、玻璃板、书架、砂岩以及跨区块边界的 `ctm_compact` 和 `overlay_*` 样例。交叉摆放并上下堆叠普通和染色玻璃板，检查连接臂、顶边和色调。为草方块、灰化土和草径各布置平地、斜坡与积雪场景，切换 Better Grass 的 `fast`、`fancy` 和多层草侧面。切换群系与光照，核对 `tintBlock`、自定义光照、图层覆盖、CTM 图集发光和 Bloom。将其中一个方块设为延迟构建，检查追加面在目标层出现一次。
- **物品与装备**：检查 GUI、主副手和掉落实体。覆盖损坏值、NBT、JSON 模型、附魔叠加、盔甲、鞘翅及最终模型的发光贴图；启用、关闭实例化分别对比。单独验证玻璃瓶及普通、喷溅、滞留药水的自动纹理，检查液体颜色和显式规则优先级。
- **颜色与随机纹理**：检查相邻群系的植物和水色、昼夜与雨雷光照、夜视和水下雾色。对普通石头应用固定色图，对格式化文本配置正文及阴影色，重载后检查已有旗帜和盾牌的染色。检查同一实体的基础纹理与叠层、随机画及方块实体，记录进出渲染距离前后的结果。检查鱼线和拴绳的纹理重复、宽度和弧度，确认画完线条后实体与后续透明物体仍正确显示。
- **天空与扩展纹理**：验证晴雨交替、日出日落、七天循环、太阳与月亮、烟花混合和动画帧时长。检查 Unicode 字体贴图、普通字体小数字宽、时钟和指南针，并在资源重载后复查。比较远距离独立纹理、动画的 mip 层和共享图集开关。

需要记录后端、光影包版本、资源包和对应的可复现场景。通过后再更新兼容矩阵与发布记录。
